# 音画匹配：10分评审规则草案

音乐编排5分，音效对应5分；每小项1分。评审者必须实际接收完整视频及音轨，并可对照指定BGM和三个原始音效。仅有截图、字幕、工程条带和波形候选不能完成听觉评价。

## 音乐编排（5分）

1. 主要视觉动作或变化与可听的重拍形成可辨认的呼应。
2. 展示段落的组织与实际选段的乐句或段落结构存在联系。
3. 音乐能量变化与运镜、显现、灯光或剪辑的强弱变化协调。
4. 音乐选段、视觉节奏及段落衔接连贯，不出现突兀的节奏中断。
5. 节奏设计服务于资产阅读，没有为追拍点而造成碎切或部件无法看清。

允许持续运镜、渐变和其他合理设计；不要求固定切镜数量、固定成片时长或每拍必切。

## 音效对应（5分）

1. whoosh与实际运动／转场区间有合理语义对应。
2. hit与显现、停顿、切换或其他明确视觉落点有合理对应。
3. drop与实际音乐或视觉重心／能量转折有合理对应。
4. 主要音效的听觉有效点／区间与对应视觉锚点在感知上对齐；结合原生帧和波形时差复核，不以文件起点直接判定。
5. 三类音效在最终混音中能辨认，层次适当；仅有条带、检测候选或原素材不等于成片中有效使用。

## 记录方式与观察边界

每项填写通过（1）／未通过（0）／证据不足（null），并提供成片时间段、听到的声音、对应的视觉事件和理由。未知项不自动当成0分或满分，若仍有未知项则保留待评状态。

模型版本、提示、解码及视频采样配置对所有候选保持一致；隐藏求解模型身份、推理、日志、其他维度分数和此前人工判定。先独立听看判断，再用程序辅助核对时间证据。

Gemini官方文档支持音视频细节理解及非语音声音分析，但默认视频采样1fps会漏掉快速事件；应按所用接口实际能力设置视频采样与补充片段。毫秒级误差使用波形和原生帧测量。音效相关有鼓点误报和音乐循环别名，不把模板候选数量当真实使用次数。

本文件是该10分的新规则草案，不声称已执行Gemini评分，不修改题面或先前冻结评测。
