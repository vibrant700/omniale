# 建议评审模板使用说明

本目录模板及配套 Schema 由助手根据评分规则整理，仅供新的独立复核参考。作者现已提供反重力导出包，音乐原提示词与音画规则原件位于 `../original-av/prompts/`，原结果与来源说明位于 `../original-av/`。未单独保存的音效原提示词不能由建议模板代替。每次新评审应记录实际使用的模型精确 ID、接口、提示词哈希、媒体哈希、视频取样/帧率设置与解码参数，并保存原始响应。模型复核有随机性，复核输出不预设与已公布分数一致。

- 音乐编排使用 `../original-av/prompts/music-frozen-prompt.md` 原件。保留其实际字段和采样要求；规范化 Schema 仅供结果整理，不替换原文件。
- `sfx-review.md`：音效对应独立上下文，提供完整成片/混音、三个原音效、原 BGM、脚本候选表及带源时间映射的原声窗口。候选表是定位假设；须实际听看确认并完整查漏。
- `dynamic-review.md`：动态画面缺陷专项规则，提供成片与原生帧；不混入六视图相似度或音画分。

JSON 输出规范见 `../schemas/`。每项需有实际时间、声音/画面观察与理由；无法观察的项用 `null`，不当成已完成评分。先独立完成判断，再与 `../results/` 的接受结果对照；不要把接受结果喂给评委。

已公布的音画评分为 Gemini 4 Neon，模型身份由委托人提供；接受结果与证据保存在 `../results/`。其中音乐 JSON 为提供结果的字段规范化版本，音效 JSON 为最终报告的结构化转录，均不伪称本包重新运行的模型响应。
