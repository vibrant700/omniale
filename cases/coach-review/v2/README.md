本题使用同一局的五名 AG 选手第一视角录像。新增的官播音轨取自 https://www.bilibili.com/video/BV1tyH76XEgz/?p=1 ，源播放时间 802.000–1825.622563 秒，以 AAC 复制提取，音轨实际时长 1023.642667 秒。开局、前期、中期、后期和终局的官播／轩染局内时钟已核对。

参测输入是五路选手录像及单独音轨，不提供官播视频。任务要求生成底部解说重点字幕，根据话语与实际画面高亮对应 AG 选手窗口，并交付成片、伤害时间轴和字幕／高亮时间轴。

`task.md` 为新版完整题面，`rubric.md` 为新版评分设计。`prepare-commentary.py --extract 802 1023.622563 --ffmpeg <ffmpeg路径>` 可下载公开源并重建音轨；在独立目录运行，素材与处理记录保存在该目录下。

声画联动评分固定为五个不同选手各一处：轩染、钟意、长生、一诺、大帅每人 4 分，共 20 分。同一人的多次高亮不能替代其他选手的独立评分节点；成片可以包含正确的额外高亮。
