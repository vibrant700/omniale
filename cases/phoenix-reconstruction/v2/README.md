# Phoenix reconstruction V2

同一案例的新版输入构建源码。原版展示页与模型结果保留在上级目录，不能用作本版测试结果。

- 时长：6 秒，30 fps，180 帧。
- 候选输入：三路同步视频、相机/场景/时间轴 JSON、五段原有 CC0 音效、题面与素材说明。
- 候选输入不含原始模型、Blender 工程、逐帧图片、动作参数曲线、目标机位真值或评分参考数据。
- 交付：可编辑 `scene.blend`、有声 `T1.mp4`、可重建的声音制作资源及说明。
- 固定权重：四机位轮廓 IoU 30，三维表面 F1 30，实际成片前景 RGB SSIM 30，完整视频音效评审 10。
- 视觉抽样：零基帧 0、20、40、60、80、99、119、139、159、179。
- 本版尚未运行模型实验，不继承原版分数。

`build_package.py` 从评测端已完成渲染的本地 V2 归档中，以允许清单构建候选包和本地展示页。评测端参考资产和真值始终留在仓库以外；无需提交到 Git。
