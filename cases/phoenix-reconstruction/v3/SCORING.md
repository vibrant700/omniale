# 凤凰评分与验收约定

总分 100：机位二维覆盖度 30、三维几何 F1 30、成片外观 20、音效 checklist 20。使用六秒参考视频和固定视觉测量定义，音频输入、交付要求与评审规则独立归档。

当前计分修订为 `phoenix-v3-iou30-f130-ssim20-audio20-r1`。2026-11-27 根据委托方要求调整权重，保留调整前的协议、原始测量和模型评审。已有结果只重算权重，不重新渲染或更改逐项判定；此次修订发生在本次模型实验之后，不称为该实验开始前冻结的权重。

视觉固定抽取零基帧 **0、20、40、60、80、99、119、139、159、179**，对应时刻为帧号除以 30。各帧等权，不做几何配准、重新缩放、图像配准或时间平移。声音检查覆盖完整 6 秒。

## 机位二维覆盖度 · 30 分

打开提交的 `scene.blend`，用固定相机 I1、I2、I3、T1 各补渲染十帧。使用 Cycles、64 采样、固定种子 17，关闭降噪、运动模糊、合成与序列编辑输出。以 α ≥ 0.5 提取前景掩膜，与参考原始 RGBA 帧的前景掩膜比较。

每对掩膜计算 IoU＝交集面积／并集面积。四机位、十时刻的 40 个 IoU 等权平均：**得分＝30 × mean₄₀(IoU)**。四个机位用于工程评分，只要求交付 T1 成片。

## 三维几何 F1 · 30 分

在参考与提交工程的十个对应姿态，提取经过骨骼及修改器求值后的世界坐标网格。透明纹理三角形按 UV 细分为 4×4 微三角形，保留中心点 α ≥ 0.5 的部分；不透明表面完整保留。

每份合并表面按面积采样 50,000 点，参考与候选随机种子分别为 20261124＋帧号和 20271124＋帧号。通过 I1、I2、I3 的投影和 BVH 首次相交测试，保留至少一个参考机位可见的样本；可见性容差为 D×10⁻⁴，D 为参考全动画联合包围盒对角线。

通过 Blender BVH 求样本到另一份完整有效表面的最近距离，容差 τ＝0.005D。P 为候选可见样本到参考表面距离不超过 τ 的比例；R 为参考可见样本到候选表面距离不超过 τ 的比例。每帧 F1＝2PR／(P＋R)，分母为零时记为 0。

**得分＝30 × mean₁₀(F1)**。此项评的是三维表面，不用图片相似度替代。

## 成片外观 · 20 分

解码实际交付的 `T1.mp4`，取相同十帧，与参考 T1 原始 RGBA 帧合成到背景 `#202630` 后比较，不能以工程补渲染替代实际成片。

比较区域为以下前景的并集：参考 α ≥ 0.5、交付工程 T1 补渲染 α ≥ 0.5，以及成片任一 RGB 通道偏离背景超过 8/255 的像素。固定裁框由全 180 帧参考前景联合范围外扩 24 像素确定；若有前景落在框外，使用完整画布。

RGB SSIM 使用高斯窗口 σ＝1.5、总体协方差。分别计算 RGB 三通道相似度图，对通道平均后在前景并集内取均值，再对十帧平均。

**得分＝20 × clip(mean₁₀(SSIM), 0, 1)**。

## 音效 checklist · 20 分

下列十项各 2 分。每项只能记“满足＝2”或“不满足＝0”；证据不足记“无法判定”，不是 0 分，也不计为有效总分，须补充有效媒体或人工复核后裁定。不使用中间分，不按完成的素材数量、轨道数量或制作方自述加分。对按旧版每项 0／1 分提交的原始评审，保留原文件，以原判定乘 2 生成单独的权重换算记录，不声称重新评审。

| ID | 检查项 | 满足条件 |
| --- | --- | --- |
| A1 | 声音质感 | 主要声音在质感、频段和体量上符合角色及可见运动的视觉语境，未出现明显无关声源 |
| A2 | 单次动作同步 | 主要振翅声的出现区间及感知重心落在相应可见运动阶段，无持续可感知的提前或滞后 |
| A3 | 连续节奏跟随 | 连续声音事件的间隔跟随实际拍翼节奏变化，无明显漏拍、额外拍点或固定等间隔替代变速动作 |
| A4 | 力度变化 | 不同运动阶段的声音强弱有可辨变化，并与动作力度和幅度形成连贯、可解释的呼应 |
| A5 | 持续时间变化 | 主要声音包络与动作持续区间相适应，不同阶段的持续时间变化合理，未用完全相同的固定包络覆盖所有动作 |
| A6 | 音色变化 | 声音的频谱明暗或质感随运动状态产生可辨且连贯的变化，变化时机与动作相符 |
| A7 | 滑翔处理 | 实际画面进入滑翔后，主要周期性拍翼声随之停止或合理衰减，剩余声部与持续运动相适应 |
| A8 | 衔接与首尾 | 声音片段之间、片头及片尾无明显剪辑跳变、点击或不合理截断；动作转换时衔接连续 |
| A9 | 音频洁净度 | 无明显削波失真、爆音、数字故障或非设计意图的突发噪声 |
| A10 | 混音层次 | 各声部形成与运动相适应的声音层次，主要动作清楚可辨，整体音量和频段关系协调，无持续遮蔽 |

同步和动态依据**提交画面的实际动作**判断，避免对参考重建误差重复扣分。若提交画面缺少节奏、幅度或滑翔等被要求恢复的变化，则对应声音配合项不能凭空获得通过；须记录“缺少可核验的相应动作”。参考视频用于确认任务动作覆盖，不用参考角色的单个动作时刻替换提交画面的时刻。

不规定骨骼角速度到响度、包络或滤波截止频率的唯一函数，不要求逐次振翅机械地服从同一物理映射。A4 检查相对力度，A5 检查时长，A6 检查音色；同一证据不能代替其他属性的证据。

### 评审步骤与有效性

1. 隐去模型名称、视觉分数和制作方评价，实际播放完整 `T1.mp4`，先独立判断音画，再用无损混音、分轨及工程定位证据。波形、频谱和制作说明仅作辅助，不能代替听音或证明声音语义。
2. 每项记录判定、对应视频时间区间、听觉与视觉依据。通过项也须记录覆盖的时间范围。A9、A10 须覆盖完整混音；局部异常记录具体发生区间。
3. 可以使用具有原生音画感知能力的多模态模型初评，但模型身份和版本必须记录，不能预先声称已获 Gemini 或其他模型评审。正式结果由指定复核者实际听看后确认；不能访问音视频时不生成分数。
4. 使用模型评同步前，以同一视频、同一音轨制作正负 250 ms 音频平移版本，检查其是否能识别人工确认的错位；另以等间隔振翅音轨检查 A3 的节奏辨别。控制版本不直接当作自然度真值。校验失败时相关项交由人工裁定，不能把模型的同步输出当成可靠分数。
5. `audio-score.json` 保存十项原始判定、时间证据、初评及复核身份、校验结果、媒体 SHA-256 和最终音效分。十项全部有效后才相加生成 0–20 分；旧版评审通过单独的 `audio-score-weighted.json` 保存权重换算，原始评审状态及限制继续适用。

本 checklist 是本题自定义规则，参考 Movie Gen 的音画匹配和声音质量维度，不是该 benchmark 的原始计分制。

页面展示约定：2026-11-27 委托方明确要求将其提供的 Gemini 4 Neon 报告纳入页面评分。本次展示采用该报告的十项原始判定，按每项 2 分换算，并同时披露未进行同步对照校准、未经人工复核及未附原始调用轨迹；不将模型评分描述为人工裁定。原始评审和此前内部审阅记录保留不变。

## 工程与来源验收 · 独立于 100 分

每项记录通过、未通过或无法核验，并附证据。验收失败不额外重复扣音效分；质量分与交付合格状态同时报告，不把缺失必需交付的结果称为完整合格交付。

| ID | 验收项 | 核验方式 |
| --- | --- | --- |
| E1 | 三维工程可编辑 | 重新打开 `scene.blend`，检查角色网格、材质、骨架、蒙皮与不同时间姿态；资源能解析 |
| E2 | 成片规格 | 解码检查 T1 为 1280×720、30 fps、180 帧、6 秒，有可解码的有效音轨，无音乐、对白或旁白 |
| E3 | 自主选材及来源 | 对照实际源文件、素材说明及实验留存的检索记录，确认所用录音来源与许可可核查，署名及再分发条件满足，不规定说明的文件格式 |
| E4 | 声音工程可编辑 | 根据交付说明用 REAPER 打开所交 `.rpp`，能独立修改片段位置、音量、效果器及自动化；源素材和依赖齐全，不能只有最终混音一条轨道 |
| E5 | 分轨与混音一致 | 根据交付说明对齐无损分轨，检查其求和能重构完整无损混音；声部名称、分组和数量由制作方自行设计，不按轨道数量加分 |
| E6 | 制作结果可重现 | 按交付说明从工程重新输出混音，核对声音事件、动态和处理；随后以混音编码成片音轨，确认未错用其他音轨 |

E5 比较编码前的无损音频，不固定采样率、位深或立体声布局。按交付约定对齐后，分轨与混音须有兼容的采样率、声道及时间基准；浮点音频逐样本最大绝对误差容差为 10⁻⁵ 满幅，存在整数音频时容差为 max(10⁻⁵, (N＋1)×2⁻ᵇ)，N 为分轨数，b 为最低整数有效位深。总线、母线处理须被合理打印进分轨。成片音轨为有损编码时不要求解码值与无损混音逐样本相等。E6 若使用随机或非确定性效果，须保留冻结／打印声部并说明重建方式。

不把某个声部名称、独立轨道或特定素材设为隐藏的必需交付。声源和层次是否合理由 A1、A10 依据实际音画判断，不以是否出现预设文件名代替听觉评价。
