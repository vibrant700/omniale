# 架子鼓音画修复 · 10／50／20／20评分规则

四个大项分别计分，五处等权；每处演奏对应10分、自然衔接4分、音色与伪影4分。定位由脚本计10分，其余90分沿用 Gemini 4 Neon（Medium）的25 fps满帧图与实际音频评审，按各子项原得分比例换算；本次没有新增模型听评。隐藏干净音轨不参与正式计分，正常录音上下文用于判断衔接与同源音色。

权重理由：演奏对应是任务核心，分配50分；进入／退出与段内连续性合计20分；现场音色与新增伪影合计20分。定位保留10分。音色和衔接不能补偿缺失的演奏内容。上述比例体现本题任务优先级，不宣称为经统计验证的通用最优权重。
