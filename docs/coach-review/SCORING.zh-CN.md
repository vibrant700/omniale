# 评分规则v5

总分100：问答事实与证据50、解说内容20、实际成片音频20、其他剪辑10。没有交付可用性分。该版更换问题及评分单位，分数不能直接当作与v4的同题模型比较。

## 问答50分

H01三时点塔状态及公告阵营各2分；H02两次本体状态各2.5分；H03两次进攻结果各2.5分；H04两处目标组成各2.5分；H05两处本体位置各2.5分；H06两段证据共同支持的身份对应4分；H08五项事实依次2、1、1、2、2分。

每个事实独立评分，要求事实正确、定位到指定事件、证据支持。只猜中枚举或布尔值，未提交对应实际证据，该事实不计分。H06两处角色对应共同构成一项关系判断，必须两处均有证据。其他题的一项错误不连坐扣除无关事实分。

H07为10分：证据链及其证明的状态转变覆盖8分；链所证明的复活与新增死亡下界各1分。覆盖按有序、可核验的不同状态转变评定，重复相同状态不增加覆盖；不提供参考变化数量或中间事件列表。超过参考覆盖的真实有效证据不会扣分。下界必须由提交的有效证据链推出，不能无证据猜数。起点死亡不计新增死亡。错误节点不证明转变，错误端点或无有效链不能仅凭两个数字得分。连续同状态节点不重复计分。

时间为证据地址，不单独奖励猜中秒数。合法代表帧须看实际画面；参考秒不是唯一答案，不按固定±10秒强制判定。位置、状态需在所选帧本身成立，附近帧只辅助辨认事件。稀疏参考之外但真实有效的证据应自动媒体核验；看不清或接口故障保持待评，不以0分替代。

## 其他50分

解说内容20：事实准确10、与实际证据一致6、解释清晰4，由GPT-6.1读取实际口播和对应画面评。问答答对不能自动给解说分，口播漏讲、错讲、与画面不同均按实际内容判断。

音频20：沿用已确认的Gemini音频口径评最终成片，必须实际听音并返回数值。不能复用其他视频的旧音频分，也不从文字稿推测声音质量。

其他剪辑10：实际场景对应5、必要事件覆盖3、章节与音画时间对应2。共享事件按唯一事件去重，不因相同片段重复出现增加覆盖分。

新题包不提供输入音频语义题；其音频分评价生成解说的质量。规则、题面、原片、私有参考和评分器在测试前冻结；不设模型得分上限，也不为达到目标分修改判分。
