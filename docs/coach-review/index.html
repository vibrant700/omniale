04 / WHERE IT GETS DIFFICULT

难度来自事件对应，而非更多选项。

01

相似画面，不同事件

商店、回城和推塔反复出现。必须确认问题所指的那一次，不能只找到一张看起来合理的图。

02

跨时间跟踪对象

对照同一建筑的状态变化，分清公告所指的阵营与屏幕上的对象，避免用后来的结果替代当轮结果。

03

答案、视频与解说一致

文字结论正确，成片也可能剪错；旁白说对了，关键证据也可能没有出现。分别核查实际交付。
