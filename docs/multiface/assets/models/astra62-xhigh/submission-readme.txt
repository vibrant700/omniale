# 双机位说话重建

`T1.mp4` 和 `T2.mp4` 是同一段表演从两个标定机位看过去的结果。两支片均由 `scene.blend` 的同一张动态人物网格渲染：切换的是相机，几何、材质、时间和原声不变。

| 项目 | 设置 |
|---|---|
| 画面 | 668 × 1024，30 fps，逐行，H.264 / yuv420p |
| 时间 | Blender 帧 1–104；首帧 0 秒，播放时长 104/30 秒 |
| 声音 | 原始 `speech.wav` 自第 1 帧起对齐；成片 AAC，48 kHz，单声道 |
| 源帧对应 | 工程帧 `n` 对应 `040434 + 3 × (n − 1)`，末帧 `040743` |

## 打开、编辑和渲染

保留 `scene.blend` 和 `assets/` 的相对位置。工程打开时使用 T1；**Performance** 集合中的人物可以单独选中和编辑。对象数据面板中的 104 个绝对形态键记录连续表演，`Evaluation Time` 随时间线线性推进。材质节点分开列出了三路相机投影，以及无拍摄覆盖处的 UV 底色。用材质预览或渲染预览检查逐帧颜色；普通实体模式显示静态 UV 参考色。原声位于视频序列编辑器的第一轨。

在本目录运行以下命令。重开和重渲染只需 **Blender 5.3**；封装 MP4 另需 PATH 中的 **FFmpeg**（含 `libx264`、AAC）。均可在 CPU 后台运行，不需要网络或外部插件。

```bash
# 直接从保存的工程渲染两支片；也可只传 T1 或 T2
blender -b scene.blend -t 4 --python-exit-code 1 -P build.py -- --render T1 T2

# 独立重建 scene.blend：从已交付的求解结果、贴图和标定重新组装
blender -b -t 4 --python-exit-code 1 -P build.py
```

渲染入口会按相机设置内参所需的像素宽高比；输出 MP4 为方形像素。每台相机先渲染无损 PNG 到系统临时目录，再用 FFmpeg 封装原声并清除临时帧。**重建会覆盖 `scene.blend`，重渲染会覆盖所选 MP4**；已手工修改的工程只需使用第一条命令。

## 场景如何得到

- **几何。** 从三张同步首帧提取头颈轮廓，通过正面与侧面的对应点求出眼、鼻、嘴、耳的空间约束。在截面网格上沿半径搜索深度，用局部纹理相关性、遮挡和邻域一致性细化表面。躯干与头颈连续，头枕和侧面画面中的背景灯独立成物体。
- **动作。** 三个机位分别估计参考帧到各帧的多尺度稠密光流；根据相机投影的局部导数及可见性，联合求解每个顶点的三维位移。唇间区域再按原片开口程度调整内凹深度。表情、目光、齿列的可见外观使用对应时刻的原片。
- **颜色。** 三组相对路径 JPEG 序列取自原始 PNG，共 312 张，保留现场照明和色调。在同一曲面上按视野、入射角和遮挡加权取样，不需要为 T1、T2 各制作一份人物。材质使用捕获光色的自发光输出，因此重新布光不会自动改变原片里的阴影。
- **标定。** 相机从原始 `K` 及 `[R|t]` 转换，未对原片重取景。捕获坐标以毫米计，工程坐标为米：`(x, z − 1052, −y) / 1000`。保留了 I1–I3 三个输入相机以及 T1、T2 两个目标相机。

**适用范围。** 这是面向本段镜头范围的表面重建。口腔和眼部并非独立的解剖模型；鼻翼、眼睑、口内等互遮区域在斜视角仍可能有少量拉伸。三路都未拍到的头顶、后脑和肩胸使用平滑外推及原材质补色。头枕的背面、厚度和单视图灯点的纵深也是估计值，不是实测的完整摄影棚。

## 资源与可选的上游复算

`assets/performance.npz` 包含捕获坐标中的参考网格、三路投影权重，以及其余 103 帧按 **0.01 mm** 量化的三维位移。`coverage.jpg` 是展开的静态补色图；`I1/`、`I2/`、`I3/` 的 `0001.jpg` 至 `0104.jpg` 与工程帧一一对应。`cameras.json` 和 `speech.wav` 是随题标定与原声的副本。

通常无需重新估计几何。要从原始 PNG 重算，在本目录执行以下命令，指定**新的工作目录**以免混用光流缓存。此步骤额外需要系统 Python、NumPy 和 Pillow；未使用预训练模型。`--output` 目录会得到新的 `assets/` 和 `build.py`。

```bash
python assets/solve/recover.py --input ../candidate \
  --work ../scratch/solve-work --output ../scratch/rebuilt
blender -b -t 4 --python-exit-code 1 -P ../scratch/rebuilt/build.py
```
