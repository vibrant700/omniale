输入材料与目标机位

三个同步输入视角与原声，目标画面不在求解材料中。

原声

48 kHz单声道，约3.47秒，与104帧画面共享同一时间轴。网页预览缩小到668×1024并合入原声；题包提供原分辨率1334×2048的无损PNG和独立音轨。

相机与时间

cameras.json指定I1–I3及T1、T2的内外参数、帧时间与图像尺寸。目标不是由文字描述猜测，而是按给定相机渲染。

用途视角原相机编号提供内容
输入I1 / I2 / I3400053 / 400029 / 400059画面＋标定
目标T1 / T2400039 / 400018仅标定
