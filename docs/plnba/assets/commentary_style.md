# 中文赛后复盘风格

面向普通篮球观众。用简洁、自然、有事件重点的普通话解释画面，允许回顾和适度留白。不要求喊叫。采用名册译名，日常可简称姓氏；戴维恩·米切尔首次出现请带名字，格林指德雷蒙德·格林时避免混淆。本场勇士穿蓝色，国王穿白色。

12 段来自同一比赛的不同时段，按 P01–P12 的编辑顺序呈现，不是连续比赛。不要编造比分走势或将相邻片段说成连续攻防。各段仅需解释提供范围内的主要事件，不要求补出未提供的回合开端。

字幕使用简体中文，与实际配音一致。旁白只使用所提供的一种 Piper 中文音色，可调整语速、断句、文本和后期声音处理。姓名读音可用同音提示字处理，但字幕和稿件应保留正确姓名。

名册来源：ESPN 当场官方数据接口公开 box score，2022-11-07 SAC–GSW（event 401468311）。DNP 球员列入参考名册，不代表在这些片段中出场。球衣号码须结合球队识别。
