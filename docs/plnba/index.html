一、这道题要做什么

篮球内容团队的真实工作

后期团队拿到十二段来自同一场比赛不同时段的无声片段，以及一份未经完整看片校正的引导稿。稿子里有正确内容，也可能错认球员、混淆传球关系、提前结束回合或误报投篮结果。目标是制作一集不超过240秒、面向普通篮球观众的中文赛后复盘。

留给智能体的判断

不能只润色原稿。智能体需要以录像为依据，决定保留什么、纠正什么、补充哪些后续动作，再选择怎样讲、哪里留白、是否慢放或回放。难点贯穿“看懂 → 改稿 → 说出来 → 与画面对齐”：稿件改对了，成片里仍然说错，也不算修复。

提供的输入与制作工具

输入包括P01–P12无声片段、源片时间清单、逐段引导稿、球队与球员名册、中文复盘风格，以及可导出的初始粗剪工程。环境提供离线Piper中文语音、Shotcut/MLT、FFmpeg/ffprobe、Python及媒体观察工具。名册帮助识别人，不提供每段的正确动作答案。

最终交付

提交含普通话解说和简体中文字幕的1080p60 MP4、独立WAV旁白、最终解说稿、SRT字幕、源片与成片对齐记录、修订证据，以及带必要媒体的可编辑工程。工程需要换路径后仍能原生重导出；把成片放进空工程不算完成。

十二段各自独立，按P01–P12呈现；允许慢放、暂停和标注清楚的回放。仅有中文旁白，允许观察留白，不要求夸张喊叫或逐次朗读运球。

制作一集中文篮球复盘

我们准备发布一集面向普通篮球观众的比赛复盘。附件有 12 段无声录像和一份初步引导稿，请根据画面核对并改写解说，制作带普通话配音和简体中文字幕的完整短片。

引导稿还没有校对，内容可能有误或不完整，请以录像为准。各段来自同一场比赛的不同时刻，彼此独立。

素材与工具

  • input/sources/P01.mp4 至 P12.mp4：比赛录像。
  • input/guide_script.md：初步引导稿。
  • input/context/：球员名册和节目风格说明。
  • input/starter/review.mlt：可修改的初始剪辑工程。
  • input/source_manifest.json：素材与时间基准。
  • input/tools/README.md：中文语音合成及媒体工具用法。
  • input/delivery_spec.md：导出规格。

环境提供中文语音合成、Shotcut/MLT、FFmpeg、Python 和媒体观察工具，制作方式由你决定。

制作要求

按 P01–P12 的顺序呈现全部片段，总长不超过 4 分钟。请把各段的主要过程讲清楚，人物、动作和结果以录像为依据，不补写素材没有提供的背景。

解说应适合直接听，表达自然、重点清楚，与画面推进相配合。使用提供的中文音色，只保留旁白，不加背景音乐或音效；字幕跟随实际配音。可以自行安排留白、慢放、暂停或回放，回放需要让观众能够区分。

沿用项目的 1080p、60 fps 设置制作 MP4，并保留便于后续修改配音、字幕和剪辑的工程及所需素材。

交付

请放到 output/：

  • commentary.mp4：完整成片。
  • narration.wav：成片实际使用的独立旁白。
  • commentary.md 和 subtitles.srt：最终解说稿与字幕。
  • project/：MLT 工程、必要媒体和重新导出说明。
  • changes.md：简述各段的主要修改，附相关源片时间。
  • alignment.json：记录各章及旁白在成片中的时间、对应源片区间，以及慢放、暂停或回放的时间映射。时间均从相应视频开头按秒计算，记录结构自行安排。

四、我们检查了什么

实际成片与字幕

完整解码202.5秒成片，全片每2秒抽帧，关键动作和实际语音定位另行核对；43条字幕与声音对应。

完整实际音轨

从最终MP4提取完整音轨，以无损FLAC送入Qwen并关闭思考；本次返回五维评价，证据校验未通过。

工程换路径重导出

交付包复制到新目录后，实际运行原生MLT完整渲染；检查25处画面、完整配音及字幕。工程独立核验，不计分。

运行与封存
