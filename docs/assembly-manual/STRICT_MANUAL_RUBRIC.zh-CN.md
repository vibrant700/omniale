# 手册与设计验收标准

版本：2026-11-17-manual-v3。适用于四组封存交付，权重仍为50/20/20/10。
本版本更新手册20分、美观与教学引导10分；问答50分、时间与音画证据20分沿用各组已完成裁定。
这属于交付验收标准更新，不能把新旧标准的分差解释为求解能力变化。

## 手册20分

事实落实6分：每题四条命题等权。通过要求手册准确、明确、完整地表达本条必需结论，并转化为读者可用的操作、检查或纠错提示。只复述现象、笼统提醒或遗漏关键对象/关系，最多部分通过。没有对应内容、实质错误或会导致读者误操作为不通过。允许手册纠正先前问答，不能因先前问答错误自动扣手册分。

图文证据8分：每题四项等权，分别核对截图来源、标注指向、图文支持、过程证据。

- 来源：关键截图须与声称的对象、阶段、源位置对应；不能因一张来源正确便认可整组。
- 指向：标注须在正常页面阅读尺寸下帮助区分具体部件/接触点。框住大半画面、箭头含糊或关键对象被遮挡，不能满分；纯粹存在箭头不构成通过。
- 图文：图、图注和正文共同支持实际操作或判断。文字正确而图中看不出所述区别，最多部分通过；图文相反为不通过。
- 过程：纠错、掉落恢复、先后变化等结论须提供能区分关键状态的前后图及对应说明。一张静帧或两张近乎同态截图，不能证明完整过程。确无过程要求的条目应按本题实际需求判断，不人为要求额外交付。

基本组织与可用性2分：主题范围、导航、操作指引、错误与示范区别、正常尺寸可读性各占0.4分。导航应能定位相应内容；仅列题号、无页码或其他有效定位方式，最多部分通过。操作指导应说明对象、动作或检查、期望状态/停止条件中本内容必需的部分；读者仍需返回录像自行还原关键步骤，不能满分。正常阅读尺寸下关键图注/编号过小、低对比或遮挡，应扣可读性。清楚的主题编排可以通过，不强制按录像时间排序。

可编辑与导出4分：原生正文、可编辑标注、正常PDF、重导出一致各1分。需要对应实际交付内容，不能以字符数量、文件存在或含有SVG扩展名代替核验。独立SVG源可满足标注编辑性，不强制Word内嵌矢量。重导出保持内容且仅有轻微字体/间距差异可通过；有明显阅读层次、图文位置或分页变化为部分通过；缺文缺图、严重错位或不可读为不通过。不得把编辑器正常的细小差异当作失败。

以上条目用pass=全分、partial=半分、fail=零分。partial表示仍可使用但有实质缺陷，不作为不愿判fail的默认选项。

## 美观与教学引导10分

视觉层级、图文布局、字体配色、教学顺序、关键点引导五项各2分，分别按0—4级换算。每项要求具体页码和观察依据，不规定必须采用某种风格。

| 等级 | 门槛 |
|---|---|
| 0 | 缺失或无法发挥该项功能 |
| 1 | 多处明显缺陷，实质妨碍阅读或学习 |
| 2 | 基本可用，但仍需读者额外寻找、放大、来回比对或自行组织步骤 |
| 3 | 大部分页面可直接顺畅使用，仅有局部轻微缺陷；需指出为何缺陷没有破坏核心任务 |
| 4 | 全册稳定达到可直接交付的质量，关键细节清楚且教学引导有效；必须列出至少两处具体优势并检查反例，不能仅凭统一配色、标题或模板给满档 |

具体要求：层级能区分动作、解释与警示；布局让关键图示获得足够空间，不能因整齐而忽略大片无效留白与局部拥挤；字体配色在正常阅读尺寸下清楚；教学顺序便于建立操作路径和错误恢复路径；引导能让读者看到具体目标与状态差别，而非仅用装饰性编号、颜色或泛指箭头。

不能预设新分必须低于旧分，不设目标总分，不按模型名称调整门槛。评委不接收旧分或旧评语。事实错误只在事实/图文项处理；设计项评价信息如何呈现，不再因同一事实错误扣设计分。同一缺陷若同时影响不同能力，须分别说明功能影响，不能复制一句评语重复扣分。接口失败不能当作交付失败；完整裁定后才汇总发布。
