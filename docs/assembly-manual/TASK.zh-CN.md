# 委托：根据装配录像制作图解操作与纠错手册

## 委托背景

培训部门希望把一次远程指导的推车装配录像整理成新员工可查阅的培训资料。

请结合录像的画面和语音回答随附的十个问题，再根据回答制作图解操作与纠错手册，帮助新员工辨认部件、理解操作要求，并在遇到典型问题时知道应该检查什么、怎样处理。

## 提供资料

- `recording.mp4`：约18分31秒的完整推车装配录像，包含第一人称操作画面和英文指导语音。
- `questions.md`：需要回答的十个问题。
- `answers-template.md`：空白答案模板。
- 素材来源与许可说明。

## 工作内容

### 回答十个问题

观看并听取录像，回答 `questions.md` 中的十个问题。观看、理解和回答可以一并进行。

在 `answers.md` 中按 Q01 至 Q10 设置标题。每题先给出直接回答问题的结论，再按下表列出依据，可按需要增添行：

| 结论编号 | 具体结论 | 源录像时间 | 对应的画面观察或语音内容 |
|---|---|---|---|
| A | | | |

时间使用原录像的 `mm:ss–mm:ss` 或秒数区间。不同事件分别定位；一条结论依赖多个片段时分别列明。可以保留必要上下文，无需毫秒精度，不要用整段录像代替具体定位。

画面描述应指出实际部件、动作或状态，不要用常识补写录像未能确认的规格、步骤或完成状态。

### 制作图解手册

根据十题回答，制作一份供新员工使用的图解操作与纠错手册。

按便于实际操作和查阅的主题组织内容，可以合并相关问题，不必每题单独成章。手册应覆盖十题涉及的关键问题，但不要求重建完整的厂商装配说明。

自行选择关键视频截图，用箭头、框或简短标签标明正文所指的部件、方向或状态。图注说明需要观察什么，并标出源录像时间。说明动作变化或操作顺序时，提供必要的前后画面。

区分错误尝试、指导要求和实际完成的动作。对相关操作说明应做什么、操作哪个对象，以及怎样检查该步是否达到要求；对典型问题说明可观察的征兆、处理方法和恢复后的检查。

请采用清楚的标题层级、图文布局和关键提示，让新员工能够找到所需内容、辨认操作对象并理解处理方法。自行决定页数和截图数量。

## 交付内容

| 文件 | 要求 |
|---|---|
| `answers.md` | 十题回答，包含结论、对应证据及源录像时间。 |
| `manual.docx` | 可编辑的图解操作与纠错手册，正文可直接编辑，截图及标注嵌入文档。 |
| `manual.pdf` | 与 Word 手册内容一致、能正常阅读的 PDF。 |
| `screenshots/` | 手册所用截图的未标注版本。 |
| `annotations/` | 可编辑标注源文件；也可直接使用文档中的原生形状。 |

将上述交付放在 `submission/` 中。标注应保留箭头、框和标签等元素的编辑能力。

可以使用 Word、LibreOffice 或其他可靠的文档制作与导出软件。交付前请打开检查文档与 PDF，确保文字、截图和标注完整显示。
