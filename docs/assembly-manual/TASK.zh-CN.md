# 委托：装配录像核查与图解培训资料

培训部门希望把一次远程指导的推车装配录像整理成新员工可查阅的操作与纠错资料。录像含错误尝试和多次纠正，请先回答核查单中的十个问题，再根据结论制作图解手册。

结合完整画面和英文语音，分清部件、指导对象、操作阶段、错误与后续处理。每题给出结论及源录像时间；相似事件分别定位。不要用常识补写录像未能确认的规格或完成状态。

手册从零制作，不提供初稿。让读者能辨认易混淆的部件、理解各阶段的要求，并在遇到典型问题时知道检查什么、怎样处理。可合并十题组织操作主题，不限定页数、截图数量或工具调用顺序。

自行选取关键视频截图，以箭头、框或简短标签标明对象、方向和状态；图注标出源时间。说明动作顺序时给出必要的前后画面；引用口头要求时说明语义及声音时间。区分错误尝试、指导目标和实际动作。

交付answers.md、manual.docx、manual.pdf，附原始截图及可编辑标注源文件。正文应可直接编辑；标注可用原生形状或SVG等源文件。图片嵌入文档，PDF正常显示。可以使用Word、LibreOffice或其他可靠导出工具。

输入为HoloAssist公开变调版本的完整18分31秒录像、十题核查单、空白答案模板及来源许可。未提供参考答案、语音转录、时间锚点或现成手册。

资料中的记录是待审素材，不能把操作者做过的全部动作当作正确示范。
