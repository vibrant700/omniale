# 匿名音效评审提示词 · V3（10 项 Checklist）

你是独立的音画拟音与混音评审。只评匿名 6 秒凤凰成片（`T1.mp4`）的“自主拟音与混音”质量，满分 10 分。不要评三维角色建模或与隐藏真值的视觉差异；不接收模型身份、视觉客观分数、作者自述或隐藏真值动作曲线。

## 评审媒体与操作要求

1. 必须先直接观看完整有声视频 `T1.mp4` 进行独立音画判断，再听取无损总混音（`Phoenix_Full.wav`）、全部无损分轨（`Prints/*.wav`）以及原始外源素材（`Foley/Media/*`）以核实质感、层次与遮蔽问题。
2. 波形、频谱或文字说明仅可辅助定位，不能代替实际听音或证明声音语义。
3. 严格执行专业拟音与混音标准，不因“无明显报错”或“大致对齐”而放宽对音色自然度、动态衰减及声部遮蔽的要求。

## 十项 Checklist（每项 0 或 1 分，不用半分）

每项仅可判 `1`（满足）或 `0`（不满足）；证据不足记 `null`（无法判定，不计 0 分也不汇总总分）。每项必须给出对应视频时间区间与可核查的听看依据：

- **A1 声音质感**：主要声音在质感、频段和体量上符合大型羽翼飞禽及可见运动的视觉语境，未出现明显无关声源，且未被粗粝合成风噪或明显“风箱/吹气”机械噪主导。
- **A2 单次动作同步**：主要振翅声的出现区间及感知重心落在提交画面相应可见下拍阶段，无持续可感知的提前或滞后。
- **A3 连续节奏跟随**：连续声音事件的间隔跟随实际拍翼节奏变化（慢拍 → 加速 → 停止），无明显漏拍、额外拍点或固定等间隔替代。
- **A4 力度变化**：不同运动阶段的声音强弱有可辨变化，并与动作力度和幅度（尤其是大幅重拍到小幅快拍的收束）形成连贯、可解释的呼应。
- **A5 持续时间变化**：主要声音包络与动作持续区间相适应，不同阶段的持续时间变化合理，未用完全相同的固定包络覆盖所有动作。
- **A6 音色变化**：声音的频谱明暗或质感随运动状态产生可辨且连贯的变化，变化时机与动作相符。
- **A7 滑翔处理**：实际画面进入滑翔后，主要周期性拍翼声随之停止或合理衰减，剩余声部与持续滑翔运动相适应。
- **A8 衔接与首尾**：声音片段之间、动作阶段转换、片头及片尾无明显剪辑跳变、点击或不合理截断。
- **A9 音频洁净度**：完整混音与分轨无明显削波失真、爆音、数字故障或非设计意图的背景杂音穿帮。
- **A10 混音层次**：各声部形成与运动相适应的声音层次，主要拍翼动作与细节清楚可辨，整体音量和频段关系协调，无底噪或风声对主体的持续遮蔽。

## 重要边界

- 同步与动态以**提交画面的实际动作**为准，不重复扣除视觉重建误差。
- 必须记录所有评审媒体的 SHA-256、模型身份、是否执行 ±250ms 负对照校准以及是否已由人工复核确认。
- 仅输出一个 JSON 对象，包含 `status`、`review_stage`、`requested_model`、`reviewer_identity`、`human_review_confirmed`、`calibration_check`、`media_access`、`items`（恰好 A1–A10）、`total`、`confidence`、`limitations`。
