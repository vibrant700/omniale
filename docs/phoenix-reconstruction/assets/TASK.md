# 凤凰角色重建与新机位有声动画制作

工作室只有一段凤凰动画的三个同步参考机位视频，需要补制指定新机位的有声镜头，并保留可继续修改的三维工程。

请使用 Blender，根据参考录像重建凤凰的形体、外观及骨骼动画，按附件中的目标相机 T1 和原时间轴输出视频。请结合提供的音效素材自主完成配音和混音，使声音与画面动作自然对应。

提供的材料：

- 三个同步参考机位视频。
- 参考机位与目标机位的相机参数、时间轴及场景配置。
- 音效素材及来源说明。

成片要求为 1280×720、30 fps、100 帧，约 3.33 秒。保持指定机位和参考动作的时间关系。

请交付至 `submission/`：

- `scene.blend`：可编辑的角色、材质、骨骼动画及目标相机。
- `T1.mp4`：目标机位的有声成片。
- 可修改并重新输出的声音制作工程或脚本，以及所需资源；也可包含在 Blender 工程中。
- `README.md`：工程打开、编辑和重新输出说明，以及素材署名。
