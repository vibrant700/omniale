# 采样率与混叠教学短片（0.3.1-draft）
## 现实场景
教师需要一段风格协调的教学短片，帮助没有信号处理基础的大学新生理解采样率与混叠。

## 任务要求
制作约60—120秒中文教学片，先提出问题，再用一个可检查的例子动态演示，最后说明结论。

短片需包含：
- 用一个含两个不同频率成分的信号，对比足够与不足的采样条件；不足条件应体现一个成分保留、另一个发生混叠。参数自行选择，不能把混叠解释成所有声音一起变低。
- 至少用一处连续动画呈现采样条件改变及其对取样的影响，保留可跟踪的对象标记；仅切换两张结果图不能完整满足此项。
- 给观众一次容易混淆的判断，并用例子澄清；用与稳定演示状态对应的实际声音支持比较，不能靠改变标签或替换无关声音充数。

动画变化、标记、旁白和字幕须对应同一事实与阶段。示例参数、叙事、镜头和视觉风格自主设计，参考片仅供参考。

## 输入
- input/knowledge.md：教学目标、受众、术语与知识事实。
- input/：可选音频素材、风格参考短片及素材说明。
- STYLE.md：风格与可读性要求。
- tools/：基础动画模板、字体说明及配音入口，使用方法见tools/README.md。

可使用、改编已有素材或自行生成。自行编写脚本与时间轴，并核验所选示例的参数和结果。

## 输出
教学MP4、讲解文本与实际音轨、字幕、可编辑或可重建工程、素材与关键事实对应表。

## 验收
知识与例子正确35分；实际动画清楚呈现关键关系25分；讲解/字幕/画面阶段一致20分；可读性与风格10分；工程与交付10分。以实际成片和交付文件为验收依据。

核心概念错误、示例结果错误、以文字或静态PPT冒充动态演示均不通过。
