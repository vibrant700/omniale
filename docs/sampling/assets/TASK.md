# 采样率与混叠教学短片

## 现实场景
教师想把一个小知识点做成有统一视觉风格的短片，用动画、例子和讲解帮助学生理解。这里的 vibe 指风格协调，不是只评“高级感”。

## 任务要求
本题选择的概念是“采样率与混叠”。制作约 60—120 秒的中文教学片。要先提出问题，再用一个可检查的例子演示，最后说明结论。动画变化、标记、旁白和字幕对应同一个事实，不能讲对但画错。允许自主设计，不要求照抄参考风格。

例子和参数可以自行选择，也可使用提供的示例素材；不强制指定频率、采样率或播放固定数量的声音片段。

## 输入
- input/knowledge.md：知识事实、教学目标、受众、术语及常见误解；不给完整成片脚本和全部时间轴。
- input/audio/ 与 input/manifest.json：可选例子素材及生成条件，不要求全部使用。
- input/style_reference.mp4 与 STYLE.md：短音视频风格参考及可读性说明，不是唯一画面标准。
- tools/：基础动画模板、使用说明与配音引擎入口。用于减少脚手架代码，不包含本题成片或分镜。
- input/SOURCES.md：素材和资料来源。

受众为没有信号处理基础的大学新生。教学目标是让观众理解采样率的含义，以及采样条件不足时可能出现的混叠。知识资料须在正式测试前由教师审核；配音引擎和模板须在所有模型使用的同一环境中预检。

## 输出
在 submission/ 中提交：
- 教学 MP4。
- 讲解文本与实际音轨。
- 字幕。
- 可编辑或可重建工程及必要使用说明。
- 素材与关键事实对应表：说明所用素材、关键事实或示例结果及其成片位置。可用 Markdown、表格或 JSON，不限定固定字段。

## 验收
知识与例子正确 35 分；实际动画清楚呈现关键关系 25 分；讲解、字幕、画面阶段一致 20 分；可读性和明确风格约束 10 分；工程与交付 10 分。对每个知识点查成片证据，不评分抽象“启发性”或未经测量的学习效果。

核心概念错误、示例结果错误、仅交文字或静态 PPT 冒充要求的动态演示，均不通过。

保留创作，不扩大成科学模型研发。提供基础动画工具，防止大量脚手架代码主导难度。本题归音视频制作，不单独证明原生感知优势。
