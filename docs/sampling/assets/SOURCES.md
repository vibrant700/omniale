# 素材来源

音频由本题历史素材脚本authoring/build_case.py按数学信号生成：48 kHz存储采样率、余弦信号、统一包络和短淡入淡出，不包含真人录音或商业音乐。

- source_3000.wav：3 kHz原始单音。
- source_1000.wav：1 kHz原始单音，与历史safe_1000.wav音频字节相同；名称不表示它在任意采样条件下都安全。

两段都是可选原始素材，不是指定的完整示例。参数、时长和文件哈希见manifest.json。当前题包不含预制混叠、滤波或升采样结果。

动态风格参考为程序原创几何动画，只展示配色、留白和运动节奏，不含教学答案。字体使用说明见tools/README.md，字体文件不随包分发。

自建音视频允许在本Case中复制、编辑和再分发；知识资料为自写摘要，来源链接见knowledge.md，外部文献保持各自版权，不随包分发。
