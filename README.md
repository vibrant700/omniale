# OmniALE 案例仓库

统一构建和展示专业音视频智能体评测案例。

- 案例目录：https://vibrant700.github.io/omniale/
- 采样率与混叠：https://vibrant700.github.io/omniale/sampling/

GitHub Pages发布目录为main分支的/docs。每个Case使用独立子目录，在docs/index.html维护案例入口。页面使用原生HTML/CSS/JavaScript，无构建依赖。

公开内容仅包含题面、原创候选素材、候选包、评分结构和真实测试状态。尚无独立盲测成绩；已有两次同会话流程试测，原片和轨迹在本地封存。不包含私有参考成片、答案目录或评分器。

本地预览：python -m http.server 8765 --directory docs

页面波形演示是额外的科普交互，不是受测模型答卷或实验结果。示例声音为程序合成；来源和方法随候选包提供。

当前题面为0.3-draft：按“提出问题、用可检查的例子演示、说明结论”组织教学片，示例参数自主选择，本版要求双成分对照、连续条件变化与实际声音对应。基础动画模板源码在 cases/sampling/tools/，候选ZIP中包含相同工具。旧版固定频率、三段试听、编码规格和80分通过线不再作为要求。本机配音、媒体验收与独立目录重建已实际完成；正式教师审核和统一受测环境预检仍待完成。
